# Tkinter Login Table

A simple Python desktop application built with Tkinter and ttk.Treeview that generates and displays random user login data (First Name, Last Name, and Email)

# Features

Displays tabular data cleanly using standard UI components.

Uses Python's random.choice to dynamically generate mock user records.

Styled column headers for better readability.


Preview

The application generates 100 sample user entries with auto-generated emails formatted as firstname.lastname@email.com.
